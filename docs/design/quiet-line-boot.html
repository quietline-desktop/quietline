Quietline — меню загрузки и экран входа

Макет к спеке docs/superpowers/specs/2026-11-02-boot-and-greeter-design.md. Меню GRUB нарисовано в пикселях экрана 1920×1200, экран входа — в логических пикселях при масштабе 1.25.

Меню загрузки. Пункты прямо на обоях Quietline, выбранный — капсула акцента; под меню место на семь пунктов, лишние прокручиваются. Подменю снимков grub-btrfs и Windows — обычные пункты. Отсчёт исчезает, когда нажата любая клавиша.

GNU GRUB version 2.16 Minimal BASH-like line editing is supported. For the first word, TAB lists possible command completions. Anywhere else TAB lists possible device or file completions. ESC at any time exits. grub> ls (proc) (hd0) (hd0,gpt8) (hd0,gpt7) (hd0,gpt6) (hd0,gpt5) (hd0,gpt1) grub> _

Экран входа. Как экран блокировки, но на обоях Quietline. Последний пользователь уже выбран, поле пароля в фокусе. Капсула сеанса видна, если сеансов больше одного. Справа снизу — «Перезагрузить» и «Выключить».
