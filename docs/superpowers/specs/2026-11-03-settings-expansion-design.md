# Окно «Настройки»: мониторы, ввод, сон, дата и время, приложения по умолчанию, панель и док

**Статус:** решения пользователя 2026-11-03 (все предложенные разделы, страницы шире и по центру, без Superpowers); план — `docs/superpowers/plans/2026-11-03-settings-expansion.md`.

**Основа:** окно «Настройки» — план `2026-10-20-system-panels.md` и спека `2026-11-01-shell-redesign-design.md`; макет `docs/design/quiet-line-b.html` (сцена «Настройки»); токены — `DESIGN.md`; минимальные версии — `AGENTS.md` (Hyprland 0.55, Quickshell 0.3.2).

## Проблема

Аудит окна 2026-11-03 (оболочка из репозитория, ноутбук 1920×1200 на 125 % и LG 2560×1440 на 100 %, снимки всех десяти страниц):

1. **Вёрстка.** Движок открывает окно на 60 % монитора (1536×846 на LG), а страницы ограничены 640 px и прижаты влево — справа пустая половина окна.
2. **«Экран и яркость».** Разрешения и частоты нет: LG работает на 59,95 Гц, хотя Hyprland предлагает 2560×1440@74,96. `quietline-shell display` и `quietline.lua` всегда пишут `mode = "preferred", position = "auto"` — выбор масштаба заодно сбрасывает режим и положение из `hyprland.lua`. Группы «Мониторы» и «Масштаб» — два списка одних и тех же мониторов.
3. **Мыши, тачпада и повтора клавиш нет** — только правкой `hyprland.lua`.
4. **«Язык и регион».** «Текущая раскладка: Russian» — английское имя раскладки от Hyprland.
5. **«Звук».** Выбора микрофона нет (только выходы), громкости приложений нет; ползунок до 100 %, хотя сервис держит до 150 %.
6. **«Питание».** Только профиль; сроки блокировки, отключения экрана и сна зашиты в `hypridle.conf` (5 / 5,5 / 15 минут).
7. **Макет.** Раздела «Панель и док» нет; у «Уведомлений» квадрат `#ff453a`, в макете `#5e5ce6`.
8. Часового пояса, синхронизации времени и приложений по умолчанию нет.

## Решение

### Разделы

| Группа | Разделы (id) |
|---|---|
| 0 | Сеть `network`, Bluetooth `bluetooth` |
| 1 | Звук `audio`, Экран и яркость `display`, Мышь и тачпад `mouse` (новый), Клавиатура `keyboard` (новый), Питание `power` |
| 2 | Оформление `appearance`, Панель и док `dock` (новый), Уведомления `notifications` |
| 3 | Язык и регион `region`, Дата и время `datetime` (новый), Приложения по умолчанию `apps` (новый), Сочетания клавиш `shortcuts`, О системе `about` |

`open("keyboard")` открывает новый раздел «Клавиатура» (раньше — «Язык и регион»). Каждый новый раздел ищется по своим ключевым словам на обоих языках.

### Вёрстка

Страница — колонка шириной до 720 px по центру области справа от боковой панели; группы и компоненты занимают всю ширину колонки. Размер окна по-прежнему задаёт движок.

### Экран и яркость

Яркость — как была. Ниже — по группе на каждый монитор (заголовок — «Встроенный экран» или описание монитора, пояснение — разъём):

- **Разрешение** и **Частота** — выпадающие списки. Разрешения — уникальные `W×H` из `availableModes` по убыванию площади; частоты — для выбранного разрешения по убыванию, подпись «74,96 Гц». Выбор разрешения берёт наибольшую частоту для него. Первый пункт обоих — «Авто» (`preferred`).
- **Масштаб** — сегменты, как раньше.
- **Расположение** — только при двух и больше мониторах: сегменты «Авто», «Слева», «Справа», «Сверху», «Снизу» (`auto`, `auto-left`, `auto-right`, `auto-up`, `auto-down` — положение относительно уже размещённых мониторов).
- **Поворот** — выпадающий список: «Нет», «90°», «180°», «270°» (`transform` 0–3).
- **Переменная частота (VRR)** — сегменты «Выкл.», «Вкл.», «В полноэкранном» (`vrr` 0, 1, 2).

**Подтверждение.** Смена разрешения, частоты, расположения или поворота применяется сразу, и под группой появляется строка «Оставить эти настройки? Вернётся через N с» с кнопками «Оставить» и «Вернуть». Через 15 секунд без ответа прежние значения монитора записываются обратно — чёрный экран не остаётся навсегда. Масштаб и VRR подтверждения не требуют.

Основного монитора у Hyprland нет — пункта нет. Выключение и зеркалирование мониторов в эту итерацию не входят: ошибка оставляет без экрана.

**Контракт `quietline-shell display`** (обратно совместим):

- ответ — `{"monitors": {"<монитор>": {"scale"?, "mode"?, "position"?, "transform"?, "vrr"?}}, "outputs": [...]}`; монитор — `desc:<описание>` или имя разъёма, как раньше; `outputs` — подключённые мониторы из `hyprctl monitors -j` (`name`, `description`, `output`, `width`, `height`, `refreshRate`, `scale`, `transform`, `vrr`, `x`, `y`, `modes: [{width, height, refresh}]`), вне Hyprland — `[]`; поле `scales` (монитор → масштаб) остаётся для прежних читателей;
- `--set {"output", <поля>}` — одно или несколько полей: `scale` (0,5–4 или `"auto"`), `mode` (`"WxH@R"` или `"auto"`), `position` (`auto`, `auto-left`, `auto-right`, `auto-up`, `auto-down`), `transform` (0–3), `vrr` (0–2); `"auto"` или значение по умолчанию убирает поле; в ответ — `"applied"`;
- файл `display.json` версии 2 (`{"version": 2, "monitors": {...}}`); версия 1 (`scales`) читается и при записи переводится;
- `display.lua` — `return { ["<монитор>"] = { scale = 1.25, mode = "2560x1440@74.96", position = "auto-right", transform = 0, vrr = 0 } }`; `quietline.lua` понимает и прежнее число (масштаб); отсутствующее поле — `preferred`, `auto`, `auto`;
- применение — `hyprctl eval 'hl.monitor({...})'` со всеми полями монитора.

Поля `hl.monitor` (`mode`, `position`, `scale`, `transform`, `vrr`) и направления `auto-*` есть в Hyprland 0.55.0 (`LuaBindingsConfigRules.cpp`, `m_autoDir`).

### Мышь и тачпад

| Группа | Пункт | Значение Hyprland |
|---|---|---|
| Мышь | Скорость указателя — ползунок −1…1 | `input.sensitivity` |
| | Ускорение — переключатель | `input.accel_profile` `adaptive` / `flat` |
| | Естественная прокрутка | `input.natural_scroll` |
| | Скорость прокрутки — ползунок 0,25…3 | `input.scroll_factor` |
| | Основная кнопка — «Левая» / «Правая» | `input.left_handed` |
| Тачпад (только если есть тачпад в `hyprctl devices`) | Касание для щелчка | `input.touchpad.tap_to_click` |
| | Естественная прокрутка | `input.touchpad.natural_scroll` |
| | Отключать при наборе | `input.touchpad.disable_while_typing` |
| | Скорость прокрутки — ползунок 0,25…3 | `input.touchpad.scroll_factor` |

Скорость указателя общая для мыши и тачпада (`input.sensitivity`): отдельная скорость тачпада через `hl.device` по имени устройства — не в эту итерацию.

### Клавиатура

- **Повтор клавиш:** «Задержка до повтора» (ползунок 150–1000 мс, `input.repeat_delay`), «Скорость повтора» (10–60 символов в секунду, `input.repeat_rate`), поле «Проверить повтор».
- **NumLock при входе** — `input.numlock_by_default`.
- **Раскладки** — группа переезжает сюда из «Языка и региона» без изменений; текущая раскладка подписывается по-русски или по-английски (`Models.layoutLabel` по коду из имени Hyprland).

**Контракт `quietline-shell input [--set JSON] [--path PATH]`** — `{"pointerSpeed", "acceleration", "naturalScroll", "scrollSpeed", "leftHanded", "tapToClick", "touchpadNaturalScroll", "disableWhileTyping", "touchpadScrollSpeed", "repeatDelay", "repeatRate", "numlock", "touchpad"}`: значения по умолчанию — значения Hyprland (0, ускорение, выкл., 1, выкл., вкл., выкл., вкл., 1, 600, 25, выкл.); `touchpad` — есть ли тачпад (только чтение). `--set` — часть полей; пишет `input.json` и `input.lua` рядом, применяет `hyprctl eval 'hl.config({ input = {...} })'`, в ответ — `"applied"`. `quietline.lua` подключает `input.lua` под `pcall`. Ключи Lua с подчёркиванием (`tap_to_click`; `tap-to-click` — ошибка), проверены `hyprctl eval`.

### Питание: блокировка и сон

Новая группа «Когда компьютер не используется» на странице «Питание»:

- «Блокировать через» — 1, 2, 5, 10, 15, 30 мин, «Никогда» (по умолчанию 5);
- «Гасить экран через» — 1, 2, 5, 10, 15, 30 мин, «Никогда» (по умолчанию 5); если срок совпадает с блокировкой, экран гаснет на 30 секунд позже — сначала виден экран блокировки, как сейчас;
- «Засыпать от батареи через» — 10, 15, 30, 60 мин, «Никогда» (по умолчанию 15); от сети сна по простою нет, как раньше.

**Контракт `quietline-shell idle settings [--set JSON] [--path PATH]`** — `{"lock", "screenOff", "suspend"}` в минутах, 0 — никогда. Запись — `idle.json` и рядом `hypridle.conf` (общий блок как у `config/hypridle/hypridle.conf`, слушатели по срокам), затем hypridle перезапускается с новым файлом (`pkill -x hypridle`, новый процесс в своей сессии); в ответ — `"applied"`. `quietline.lua` при старте берёт `quietline/hypridle.conf` каталога настроек, если он есть, иначе общий файл пакета. `idle suspend` не меняется.

### Дата и время

- Текущие дата и время крупно, часовой пояс.
- «Устанавливать время автоматически» — переключатель (`timedatectl set-ntp`).
- «Часовой пояс» — строка с текущим поясом и кнопкой «Изменить…»: под строкой раскрывается поле поиска и список поясов (`timedatectl list-timezones`), выбор — `timedatectl set-timezone`.
- «Часы 24/12» и «Дата на панели» переезжают сюда из «Языка и региона» без изменений; там остаются язык и формат даты.

**Контракт `quietline-shell time [--set JSON] [--zones]`** — `{"timezone", "ntp"}`; `--zones` — `{"zones": [...]}`; `--set {"timezone"}` или `{"ntp"}` — `timedatectl`, ответ — новое состояние или `{"error"}`. Правило polkit `config/polkit/50-quietline-time.rules` разрешает `org.freedesktop.timedate1.set-timezone` и `set-ntp` активному локальному пользователю из `wheel` без пароля — так же, как сетевое правило: агент polkit в сеансе не запущен.

### Приложения по умолчанию

Группа строк с выпадающими списками:

| Категория | Типы |
|---|---|
| Браузер | `x-scheme-handler/http`, `x-scheme-handler/https`, `text/html` |
| Файлы | `inode/directory` |
| Почта | `x-scheme-handler/mailto` |
| Текст | `text/plain` |
| Изображения | `image/png`, `image/jpeg`, `image/webp`, `image/gif` |
| Видео | `video/mp4`, `video/x-matroska`, `video/webm` |
| Музыка | `audio/mpeg`, `audio/flac`, `audio/ogg` |
| PDF | `application/pdf` |

Кандидаты — видимые desktop-файлы (`NoDisplay`, `Hidden` не `true`) из `$XDG_DATA_HOME/applications` и `$XDG_DATA_DIRS/*/applications`, у которых в `MimeType` есть первый тип категории; текущее — `xdg-mime query default` первого типа. Терминала нет: `Super+Enter` запускает Ghostty из `quietline.lua`, общего стандарта терминала по умолчанию нет.

**Контракт `quietline-shell defaults [--set JSON]`** — `{"categories": [{"id", "current", "apps": [{"id", "name"}]}]}`; `--set {"category", "app"}` переписывает в `$XDG_CONFIG_HOME/mimeapps.list` раздел `[Default Applications]` для всех типов категории (остальные разделы и строки сохраняются), ответ — новое состояние.

### Панель и док

- Группа «Панель»: «Процент заряда на панели» (переезжает из «Оформления»).
- Группа «Док»: «Прятать док автоматически» — переключатель (по умолчанию вкл., как сейчас). Выкл. — док виден всегда и резервирует место внизу (`exclusiveZone`), окна его не перекрывают.
- Группа «Закреплённые»: приложения дока по порядку — значок, имя, кнопки «↑», «↓», «Открепить» (`desktop.movePin`, `desktop.togglePin`).

Поле `dockAutohide` (`true` | `false`) добавляется в `quietline-shell appearance` и `appearance.json`.

### Звук

- Ползунок громкости выхода в окне — до 150 %, как у сервиса.
- Группа «Микрофон»: уровень и список устройств ввода с галочкой у текущего (`Pipewire.preferredDefaultAudioSource`).
- Группа «Приложения»: потоки вывода (`Stream/Output/Audio`) — имя приложения, ползунок громкости и кнопка звука; пусто — «Звук сейчас не воспроизводится».

### Мелочи

- Квадрат «Уведомлений» — `#5e5ce6`, как в макете.

### Выпадающий список

Новый элемент `inputs/ShellSelect.qml`: поле 26 px с подписью выбранного и стрелкой; по щелчку — всплывающий список (`Popup` в окне) со строками `ShellMenuItem`, галочка у выбранного, прокрутка при длинном списке, клавиши ↑ ↓ Enter Esc.

## Не входит

VPN (из макета), отдельная скорость тачпада, выключение и зеркалирование мониторов, основной монитор, терминал по умолчанию, уведомления по приложениям, «О системе» — отдельными задачами.
