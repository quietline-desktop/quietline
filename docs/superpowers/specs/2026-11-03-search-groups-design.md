# Поиск `Super+Space`: группы при пустом поле и плавный список

**Статус:** решения пользователя 2026-11-03 (группы как в меню Omarchy, ввод — всегда глобальный поиск, только базовые группы, без Superpowers); план — `docs/superpowers/plans/2026-11-03-search-groups.md`, живая проверка — `docs/backlog.md`.

**Основа:** поиск — план `2026-10-28-daily-actions.md` (D19–D21), вид — спека `2026-11-01-shell-redesign-design.md` и макет `docs/design/quiet-line-b.html` (сцена «Поиск»), токены — `DESIGN.md`.

## Проблема

Поиск работал, но выглядел неровно: при наборе список и окно дёргались, переходов не было. Аудит `search/SearchPanel.qml`, `search/SearchService.qml`, `Models.searchResults`/`searchSections` и `ShellPopup` нашёл причины:

1. **Файлы сбрасываются на каждый символ.** `SearchService.onQueryChanged` обнулял `files`, ответ `quietline-shell files` приходил через 250 мс и позже. Раздел «Файлы» исчезал и появлялся заново при каждом нажатии — список и окно сжимались и росли дважды за символ.
2. **Модель списка — массив JS.** `model: root.rows` пересоздавал все делегаты на каждое изменение: значки приложений загружались заново и мигали запасным символом, подсветка выбора перерисовывалась без перехода.
3. **Окно меняет размер на каждый символ.** `panelHeight` шёл за `list.contentHeight`, поверхность слоя Wayland переразмечалась без анимации; кадр с прежним размером виден как скачок.
4. **Выделение уходит за указателем.** Выбор менялся по `onEntered`: строка, появившаяся под неподвижным указателем во время набора, забирала выделение.
5. **Расхождения с макетом:** пустое поле показывало первые 40 приложений в порядке desktop entries; подсказка «↵ открыть» появлялась и пропадала вместе с результатами; число вычисления — 20 px Light вместо 22 px 300.

## Решение

### Поведение

- Поле поиска — сверху, как раньше (54 px, шрифт 21 px).
- **Пустое поле — список групп** по образцу меню Omarchy (берётся только взаимодействие): «Приложения» (все программы по алфавиту), «Действия» (снимок области, история буфера, блокировка), «Питание» (выход из сеанса, перезагрузка, выключение), «Настройки» (разделы окна «Настройки»). У группы значок, название, короткое пояснение и шеврон.
- ↑/↓ выбирают строку, Enter или → открывают группу; внутри группы Enter выполняет пункт, ← , Backspace на пустом поле и Esc возвращают к списку групп, выбор встаёт на группу, из которой вышли. Esc в корне закрывает окно. Над полем в открытой группе — плашка с её названием.
- **Любой ввод — глобальный поиск** по всем источникам, как раньше (вычисление, лучшее совпадение, приложения, действия и разделы настроек, файлы); открытая группа при этом закрывается, очистка поля возвращает к списку групп.
- Подсказка справа в поле видна всегда и зависит от состояния: в корне «→ открыть группу», в группе «← назад», в результатах «↵ открыть».

### Плавность

- **Файлы не сбрасываются при наборе.** Пока ответ на новый запрос не пришёл, прежний список файлов фильтруется тем же правилом, что у `plocate -b -i` (имя содержит запрос без учёта регистра): при дописывании символов файлы только уходят, новые добавляются, когда придёт ответ. Пока ответ не пришёл и ничего не найдено, вместо «Ничего не найдено» — «Ищу файлы…».
- **Строки результатов не пересоздаются.** Список результатов — `ScriptModel` Quickshell с ключом `key` (вид и идентификатор): совпавшая строка остаётся тем же делегатом, свежие данные строки берутся по ключу. Появление и уход строк — затухание со сдвигом, сдвиг соседних — плавный (120 мс).
- **Окно не переразмечается при наборе.** Поверхность слоя поиска держит наибольшую высоту (поле и 420 px списка); меняется только высота видимой карточки — плавно, 180 мс. Щелчки мимо карточки проходят насквозь, как раньше (маска по карточке). Высота считается из строк (`Models.searchListHeight`), а не из `contentHeight` списка.
- **Выделение — одна подсветка, которая переезжает** к выбранной строке (120 мс), цвет текста меняется переходом. Выбор под указателем меняется только при движении мыши.
- **Переходы между режимами:** корень ↔ группа — сдвиг страницы по горизонтали с затуханием (вперёд — справа, назад — слева); группы ↔ результаты — затухание со сдвигом по вертикали.
- **Ограничение анимаций** (`quietline-shell motion`, `reducedMotion` панели): все переходы мгновенные.

### Вид

Строки по макету: 40 px, скругление 9, значок 28 px, заголовок 14 px, у файлов путь ниже, вычисление — 22 px Light. Подписи разделов — 11 px заглавными. Цвета и размеры — токены `Theme.qml`, новых токенов нет.

## Границы

- Новых источников нет («Открытые окна» и «Недавние» — не в этой задаче), формат `quietline-shell files` не меняется.
- Буфер `Super+V` не меняется; `ShellPopup` получает общие свойства высоты поверхности и плавной высоты карточки, которые включает только поиск.
- Сторонний код не копируется: из Omarchy взята только идея меню групп.
