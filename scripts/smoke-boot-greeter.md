# Живая проверка темы GRUB и экрана входа

Проверка по спеке `docs/superpowers/specs/2026-11-02-boot-and-greeter-design.md` и плану `docs/superpowers/plans/2026-11-02-boot-and-greeter.md` на ноутбуке с Arch (GRUB, Btrfs, Windows рядом), после установки пакета `quietline` из этой ветки и шагов установщика «Экран входа» и «Тема меню загрузки». Модульные тесты проверяют `quietline-shell greeter` (пользователи, сеансы, последний выбор), шаблон greetd, шаг темы GRUB и откат по журналу; здесь — то, что подтверждается только загрузкой и входом. Пока пункт не проверен, он числится в `docs/backlog.md`.

Нумерация: **B1–B15**.

## Подготовка

```sh
./install.sh update                  # пакет из клона: quietline-greeter, тема GRUB, правило tmpfiles
./install.sh --from greetd           # шаблон greetd с quietline-greeter, затем «Тема меню загрузки»
grep -E '^#?GRUB_(THEME|TERMINAL)' /etc/default/grub
ls -ld /var/lib/quietline-greeter    # владелец greeter, права 0750
```

Тему без перезагрузки можно посмотреть в QEMU: `scripts/preview-grub-theme ru` (или `en`) — снимки меню и консоли в `~/.cache/quietline/preview-grub/`. Экран входа вне greetd — `qs -p shell/quietline/Greeter.qml` в сеансе (вход ответит «экран входа запущен не из greetd»; закрыть — `pkill -f Greeter.qml`).
