# Живая проверка ежедневных действий

Проверка этапа 4 по плану `docs/superpowers/plans/2026-10-28-daily-actions.md` в сеансе Hyprland ≥ 0.55 на Arch с Quickshell ≥ 0.3.2, после `scripts/smoke-quickshell.md` и `scripts/smoke-system-panels.md`. Модульные тесты (`uv run --python 3.14 pytest`, `node --test 'tests/shell/*.test.cjs'`) проверяют `quietline-shell lock|session|app|screenshot|clipboard|files`, калькулятор и ранжирование поиска без Hyprland и Quickshell; здесь — то, что подтверждается только вживую. Пока пункт не проверен, он числится в `docs/backlog.md`.

Нумерация: **D1–D24** — сценарии ниже; **РФ1–РФ5** плана — D1–D4 (РФ1), D6–D9 (РФ2), D12–D13 (РФ3), D16–D18 (РФ4), D21 (РФ5).

## Подготовка

Стенд, движок и оболочка — как в `scripts/smoke-quickshell.md` («Подготовка»). Привязки стандартного примера Hyprland удалены из `~/.config/hypr/hyprland.lua` целиком (шапка `config/hyprland/quietline.lua`). Дополнительно:

```sh
sudo pacman -S --needed grim slurp satty wl-clipboard cliphist plocate libnotify xdg-user-dirs dolphin
xdg-user-dirs-update
quietline-shell files --update
quietline-shell clipboard list
```

Понадобятся приложение с несохранённым документом (например, `kate` или VS Code с изменённым файлом), Telegram (живёт в трее) и 1Password.
