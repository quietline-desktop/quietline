# Живая проверка установщика

Проверка установщика этапа 5 по плану `docs/superpowers/plans/2026-10-28-installer.md`: сначала в виртуальной машине, затем на ноутбуке после установки Arch по [гайду](../docs/install/2026-10-20-arch-install.md). Модульные тесты (`uv run --python 3.14 pytest tests/install`) проверяют порядок экранов и шагов, команды снимка и отката, каталог, файлы пользователя и журнал на поддельной системе; здесь — то, что подтверждается только на настоящем Arch. Пока пункт не проверен, он числится в `docs/backlog.md`.

Нумерация: **I1–I16** — сценарии ниже.

## Подготовка

- Виртуальная машина: UEFI, диск 40 ГБ, Arch по разделам 3–5 гайда (Btrfs с подтомами `@ @home @log @pkg @snapshots`, EFI-раздел в `/efi`, GRUB вручную).
- Второй стенд для I8: тот же Arch, но корень ext4.
- Клон Quietline в домашнем каталоге, установщик запускается из него: `./install.sh`. Журнал — `~/.local/state/quietline/install.log`, состояние — `install.json` рядом.
- После каждого сценария, который меняет систему, — вернуть машину к снимку гипервизора.
