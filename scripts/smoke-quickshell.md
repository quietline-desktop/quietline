# Живая проверка панели и дока Quietline

Проверка этапа 2 по плану `docs/superpowers/plans/2026-10-19-quickshell.md` в сеансе Hyprland ≥ 0.55 на Arch с Quickshell ≥ 0.3.2. Модульные тесты (`uv run --python 3.14 pytest`, `node --test 'tests/shell/*.test.cjs'`) проверяют модели оболочки и `quietline-shell` без Quickshell; здесь — то, что подтверждается только в живом сеансе. Пока пункт не проверен, он числится в `docs/backlog.md`.

Нумерация: **1–37** — сценарии ниже; **РФ1–РФ5** плана оболочки — пункты 5, 19 и 35 (РФ1), 11 (РФ2), 7 и 24 (РФ3), 6 (РФ4), 17 и 18 (РФ5).

## Подготовка

Стенд и установка движка — как в `scripts/smoke-window-engine.md` (раздел «Подготовка»): `uv tool install --python 3.14 .` ставит и `quietline-engine`, и `quietline-shell` в `~/.local/bin`. Дополнительно:

```sh
sudo pacman -S --needed quickshell ttf-ibm-plex ttf-jetbrains-mono-nerd noto-fonts
qs --version                        # записать в «Результаты»
command -v quietline-shell
mkdir -p ~/.config/quickshell
ln -s ~/quietline/shell/quietline ~/.config/quickshell/quietline
```

Для ручного запуска без входа в сеанс заново:

```sh
quietline-engine serve &
scripts/run-shell
```

Для проверки интеграции войти в Hyprland с `config/hyprland/quietline.lua` (см. `scripts/smoke-window-engine.md`): движок и панель стартуют сами.

Состояние оболочки читается без снимков экрана:

```sh
qs -c quietline ipc call quietline status | jq .
```
