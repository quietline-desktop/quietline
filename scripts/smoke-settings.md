# Живая проверка расширенного окна «Настройки»

Проверка по спеке `docs/superpowers/specs/2026-11-03-settings-expansion-design.md` в сеансе Hyprland ≥ 0.55 с Quickshell ≥ 0.3.2, после установки пакета `quietline` из этой ветки (`./install.sh update` или `makepkg -si` в `packaging/arch`): правило polkit `50-quietline-time.rules` и запуск hypridle с файлом из «Настроек» появляются только с пакетом. Модульные тесты проверяют `quietline-shell display`, `input`, `idle settings`, `time`, `defaults`, разрешения и частоты, подписи сроков и разделы поиска; здесь — то, что подтверждается только вживую. Пока пункт не проверен, он числится в `docs/backlog.md`.

Нумерация: **S1–S16**.

Оболочку из репозитория без установки можно запустить вместо установленной: `pkill -fx 'qs -c quietline'; PATH="$PWD/.venv/bin:$PATH" scripts/run-shell &` (`quietline-shell` из клона: `uv run --python 3.14 --group dev true` создаёт `.venv`); раздел открывается `qs -p shell/quietline ipc call quietline settings <раздел>`. С `.venv` первым в `PATH` `powerprofilesctl` запускается не тем Python, и «Питание» пишет, что служба профилей не запущена, — это особенность запуска из клона.
