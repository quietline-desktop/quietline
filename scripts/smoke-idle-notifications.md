# Живая проверка простоя, индикатора, заряда и уведомлений

Проверка этапа 6 по плану `docs/superpowers/plans/2026-10-30-idle-osd-notifications.md` и спеке `docs/superpowers/specs/2026-10-30-idle-osd-notifications-design.md` в сеансе Hyprland ≥ 0.55 на Arch с Quickshell ≥ 0.3.2, после `scripts/smoke-daily-actions.md`. Модульные тесты (`uv run --python 3.14 pytest`, `node --test 'tests/shell/*.test.cjs'`) проверяют `quietline-shell idle suspend` на поддельном `/sys/class/power_supply`, клавиши и запуск hypridle в `quietline.lua`, пороги заряда, правила всплывания карточек, давность и предел истории; здесь — то, что подтверждается только вживую. Пока пункт не проверен, он числится в `docs/backlog.md`.

Нумерация: **N1–N20** — сценарии ниже.

## Подготовка

Стенд, движок и оболочка — как в `scripts/smoke-quickshell.md` («Подготовка»). Дополнительно:

```sh
sudo pacman -S --needed hypridle libnotify mpv
sudo install -Dm644 config/hypridle/hypridle.conf /usr/share/quietline/hypridle/hypridle.conf
pgrep -a hypridle
```

Если hypridle не запущен (сеанс начат до установки) — `hypridle -c /usr/share/quietline/hypridle/hypridle.conf &`. Для быстрой проверки сроков можно запустить копию конфигурации с уменьшенными `timeout` (например, 20/30/60 с) вместо основной; итоговая проверка — с основной. Тестовое уведомление: `notify-send -a Test "Заголовок" "Текст"`, с действием — `notify-send -a Test -A open=Открыть "С действием"` (команда ждёт выбора и печатает `open`).
