# Живая проверка языков и региона

Проверка части «Языки и регион» этапа 5 по плану `docs/superpowers/plans/2026-10-28-language-region.md` в сеансе Hyprland ≥ 0.55 на Arch с Quickshell ≥ 0.3.2, после `scripts/smoke-quickshell.md`, `scripts/smoke-system-panels.md` и `scripts/smoke-daily-actions.md`. Модульные тесты (`uv run --python 3.14 pytest`, `node --test 'tests/shell/*.test.cjs'`) проверяют `quietline-shell region`, уведомления на двух языках, таблицы строк `Strings.js`, отсутствие кириллицы в QML и `Models.js`, скрытие неустановленных программ; здесь — то, что подтверждается только вживую. Пока пункт не проверен, он числится в `docs/backlog.md`.

Нумерация: **L1–L17** (с подпунктом L9б) — сценарии ниже.

## Подготовка

Стенд, движок и оболочка — как в `scripts/smoke-quickshell.md` («Подготовка»). Дополнительно:

```sh
sudo pacman -S --needed dolphin ghostty fish git
ln -s "$PWD/config/fish/quietline-locale.fish" ~/.config/fish/conf.d/quietline-locale.fish
rm -f ~/.config/quietline/region.json ~/.config/quietline/keyboard.lua
[ -e ~/.config/locale.conf ] && mv ~/.config/locale.conf ~/.config/locale.conf.bak
```

Последние строки возвращают состояние первого входа, сохраняя `locale.conf` пользователя в `.bak`; по окончании проверки `mv ~/.config/locale.conf.bak ~/.config/locale.conf`. Текущие настройки видны командой `quietline-shell region`, раскладки в Hyprland — `hyprctl devices -j | jq '.keyboards[].layout'`. Файл `~/.config/locale.conf` подхватывается сеансом при входе (greetd `source_profile` → `/etc/profile.d/locale.sh`), поэтому пункты про другие программы проверяются после повторного входа.
