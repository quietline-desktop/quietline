# Живая проверка системных панелей и окна «Настройки»

Проверка этапа 3 по плану `docs/superpowers/plans/2026-10-20-system-panels.md` в сеансе Hyprland ≥ 0.55 на Arch с Quickshell ≥ 0.3.2, после `scripts/smoke-quickshell.md`. Модульные тесты (`uv run --python 3.14 pytest`, `node --test 'tests/shell/*.test.cjs'`) проверяют `quietline-shell network`, `about`, правило polkit и модели панелей без NetworkManager и Quickshell; здесь — то, что подтверждается только вживую. Пока пункт не проверен, он числится в `docs/backlog.md`.

Нумерация: **S1–S14** — сценарии ниже; **РФ1–РФ5** плана системных панелей — S3 (РФ1), S5 (РФ2), S6 (РФ3), S8 (РФ4), S11 (РФ5).

## Подготовка

Стенд, движок и оболочка — как в `scripts/smoke-quickshell.md` («Подготовка»). Дополнительно:

```sh
sudo pacman -S --needed networkmanager brightnessctl power-profiles-daemon bluez bluez-utils pipewire wireplumber
sudo systemctl enable --now NetworkManager bluetooth power-profiles-daemon
sudo install -m 0644 config/polkit/50-quietline-network.rules /etc/polkit-1/rules.d/
groups | grep -qw wheel && echo "wheel: yes"
quietline-shell network status | python -m json.tool
quietline-shell about
```

Понадобятся USB-Ethernet-адаптер и второе устройство в той же сети (или ноутбук с адресом на кабеле).
