# Quietline

Личное рабочее окружение Linux поверх Hyprland. Каждое рабочее пространство живёт в одном из двух режимов, переключаемых одним действием: **«Окна»** — привычные плавающие окна с доком, **«Тайлы»** — прокручиваемые колонки встроенной раскладки Hyprland `scrolling`. Поверх — спокойная собственная оболочка на Quickshell: верхняя панель, трей, поиск, история буфера, быстрые настройки, сетевая панель и уведомления. Идея двух режимов взята у [Hyprstack](https://github.com/hase9awa/hyprstack-shell); его код не используется.

**Статус:** написаны все пять этапов. Движок пространств и окон — сервис `quietline-engine` с CLI и IPC и клавиши Hyprland. Оболочка на Quickshell — верхняя панель, док, трей и показатели; закрепления дока хранит `quietline-shell`. Системные панели — сетевая панель с профилями объекта и откатом через NetworkManager, быстрые настройки звука, яркости, Wi-Fi и Bluetooth, окно «Настройки» по `Super+I`. Ежедневные действия — блокировка и меню питания, корректный выход из приложений, уведомления, снимки экрана, история буфера, поиск `Super+Space` и клавиши окон. Языки и регион — оболочка и уведомления на русском и английском, раздел «Язык и регион» в «Настройках» (язык, формат даты и времени, раскладки `us,ru`), док и памятка без неустановленных программ. Установщик — `./install.sh` с выбором языков, каталогом программ, снимком корня Btrfs и откатом, и гайд установки Arch на Btrfs. Ничего из этого ещё не проверено в живом сеансе Hyprland и Quickshell и на настоящем Arch — список в [docs/backlog.md](docs/backlog.md).

**Основа:** Arch Linux. Hyprland не ниже 0.55 и Quickshell не ниже 0.3.2 — из официального репозитория Arch.

## Этапы

1. Движок пространств и окон — Python-сервис с CLI и IPC через Unix-сокет, не зависит от панели — написан, ждёт живой проверки
2. Оболочка Quickshell — панель, док, трей, показатели, переключатель режима, анимации — написана, ждёт живой проверки
3. Системные панели — сеть и Ethernet-профили с откатом, звук, яркость, Bluetooth, питание, окно «Настройки» — написаны, ждут живой проверки
4. Ежедневные действия — поиск, снимки экрана, история буфера, уведомления, блокировка, выход из приложений — написаны, ждут живой проверки
5. Языки и регион, затем установщик и проверка на чистом Arch — сеанс входа, пакеты и приложения, повторяемость установки. Языки и регион — оболочка на русском и английском, раскладки `us,ru`, док без неустановленных программ — написаны, ждут живой проверки. Установщик — языки, каталог программ, снимок Btrfs и откат, гайд установки Arch — написан, ждёт проверки на чистом Arch.
