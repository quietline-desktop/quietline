# Quietline

Личное рабочее окружение Linux поверх Hyprland. Каждое рабочее пространство живёт в одном из двух режимов, переключаемых одним действием: **«Окна»** — привычные плавающие окна с доком, **«Тайлы»** — прокручиваемые колонки встроенной раскладки Hyprland `scrolling`. Поверх — спокойная собственная оболочка на Quickshell: верхняя панель, трей, поиск, история буфера, быстрые настройки, сетевая панель и уведомления. Идея двух режимов взята у [Hyprstack](https://github.com/hase9awa/hyprstack-shell); его код не используется.

**Статус:** первый этап — движок пространств и окон — написан: сервис `quietline-engine` с CLI и IPC и клавиши Hyprland. Проверка в живом сеансе Hyprland ещё не проведена — список в [docs/backlog.md](docs/backlog.md). Оболочка и следующие этапы не начаты.

**Основа:** Arch Linux. Hyprland не ниже 0.55 и Quickshell не ниже 0.3.2 — из официального репозитория Arch.

## Этапы

1. Движок пространств и окон — Python-сервис с CLI и IPC через Unix-сокет, не зависит от панели — написан, ждёт живой проверки
2. Оболочка Quickshell — панель, док, трей, показатели, переключатель режима, анимации
3. Системные панели — сеть и Ethernet-профили с откатом, звук, яркость, Bluetooth, питание
4. Ежедневные действия — поиск, снимки экрана, история буфера, уведомления, блокировка, выход из приложений
5. Установщик и проверка на чистом Arch — сеанс входа, пакеты и приложения, повторяемость установки

Для этапов 2–5 перед реализацией пишется отдельный план.
