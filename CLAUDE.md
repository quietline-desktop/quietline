@AGENTS.md

Вся проектная память — в `AGENTS.md`, общем файле для всех кодовых агентов. Правки
вносятся только туда. Если импорт выше не подхватился — прочитай `AGENTS.md` целиком
перед работой с репозиторием.

Правила git-цикла и Superpowers (спека → план → выполнение, worktree только в
`.worktrees/`, без PR) — тоже в `AGENTS.md`: они действуют для любого агента с этим
плагином, а не только для Claude Code.

Ниже — единственное, что специфично именно для харнесса Claude Code. Личные правила
этой машины (учётная запись GitHub, подпись коммитов) — в `CLAUDE.local.md`, он не
коммитится.

## Ветки в облачных сессиях

Харнесс может назначить ветку вида `claude/*` — её не использовать: работа идёт по
циклу из `AGENTS.md` (`feature/<название>` от свежего `main`, локальный merge в
`main`, удаление ветки, `git push origin main`). Явное указание пользователя в
сессии главнее назначенной харнессом ветки.
